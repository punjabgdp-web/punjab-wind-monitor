Data & method

Observed (past 6 h): METAR reports for Islamabad (OPIS), Sialkot (OPST), Lahore (OPLA), Amritsar (VIAR), Faisalabad (OPFA), Multan (OPMT), D.G. Khan (OPDG), Bahawalpur (OPBW) and Rahim Yar Khan (OPRK), from NOAA's Aviation Weather Center. For each hour the report closest to the hour is used.
Forecast (next 6 h): each airport's official TAF (base, FM and BECMG groups; TEMPO/PROB groups ignored).
Gaps: airports that publish no report for an hour, the city reference points and the background grid use the Open-Meteo model (10 m wind), tagged MODEL. Several smaller Punjab airports (Rahim Yar Khan, Bahawalpur, D.G. Khan) often publish no METAR, so they will usually show model values.
Updates: a GitHub Actions job rebuilds data/latest.json every 30 minutes (GitHub may delay scheduled runs by a few minutes). The page checks for a new file every 5 minutes.
Flow field: inverse-distance interpolation between sites and linear between hours. Particles fade with distance from the nearest site.
